# DeepDemand 랜딩페이지 — AI 에이전트 활용 개선 프롬프트 가이드

> 이 문서는 DeepDemand 지식 베이스(PRD, VPS, Persona Spectrum, JTBD, CJM, 경쟁사 분석)를 기반으로,
> AI 에이전트에게 랜딩페이지 개선을 지시할 때 사용할 프롬프트 패턴과 예시를 정리한 실전 가이드입니다.

---

## 1. AI 에이전트를 활용해 효과적으로 랜딩페이지 개선하기

> ***프로토타이핑 / 원샷 프롬프팅 이후의 AI 에이전트 작업 스킬 필요***

### 1.1 좋은 프롬프트의 구조

```
🎯 좋은 프롬프트 = WHAT + WHERE + HOW + WHY(Context)

WHAT: 무엇을 원하는가
• 구체적인 기능/UI 설명
• 원하는 결과물의 모습

WHERE: 어디에 적용할 것인가
• 특정 섹션/파일 지정
• 위치 관계 명시 (위/아래/앞/뒤)

HOW: 어떤 스타일/방식으로
• 색상, 레이아웃, 애니메이션
• 참고할 기존 요소

WHY: 비즈니스 맥락 (DeepDemand 고유)
• 타겟 페르소나의 감정 상태
• CJM 단계에서의 역할
• 해결하려는 고객의 Anxiety/Habit
```

> [!IMPORTANT]
> DeepDemand의 핵심 고객(이지훈, 32세 다품종 셀러)은 **매일 밤 엑셀 지옥에 지친 상태**입니다.
> 모든 카피와 UI는 "인지적 노력 제로"를 목표로 해야 합니다.
> 기술 용어(MAPE, 시계열 분석 등)가 아닌 **행동 지시어**("내일 L사이즈 블랙 50개 발주하세요")로 말해야 합니다.

### 1.2 ❌ 나쁜 프롬프트 vs ✅ 좋은 프롬프트

| ❌ 나쁜 프롬프트 | ✅ 좋은 프롬프트 |
| --- | --- |
| "히어로 섹션 다시 만들어줘" | "현재 히어로 섹션 위에 새로운 히어로 섹션을 추가해줘. 헤드라인은 '내일 발주, 5분 만에 끝내세요'로 하고, 서브타이틀은 '엑셀 파일만 올리면 AI가 SKU별 최적 발주량을 즉시 도출합니다'로 해줘" |
| "네비게이션 추가해" | "최상단에 고정 헤더 네비게이션을 넣고 싶어. 왼쪽에는 DeepDemand 로고를, 중앙에는 '기능 소개 · 작동 방식 · 고객 후기 · 요금제' 섹션 링크를, 오른쪽에는 '무료로 시작하기' CTA 버튼을 배치해줘" |
| "예쁘게 해줘" | "다크 모드 기반에 에메랄드(#10B981) 포인트 컬러로 글래스모피즘 스타일을 적용해줘. 데이터 대시보드의 신뢰감을 주는 톤으로" |
| "안 돼" | "엑셀 업로드 데모 영역에서 드래그할 때 텍스트가 블록 지정되는데, 이걸 막고 대신 파일 드롭 영역이 하이라이트 되게 해줘" |

### 1.3 상세 팁

| 상황 | DeepDemand 맥락에서 이렇게 말하세요 |
| --- | --- |

## 2. 새로운 히어로 섹션 추가하기

> [!TIP]
> **DeepDemand CJM 1단계 (Trigger)** 에 해당합니다.
> 고객(이지훈)이 품절 사태 직후 "이 지옥에서 벗어날 방법이 없을까?" 하는 순간을 저격합니다.
> 기술적 우수성이 아닌 **"오늘 밤 내 퇴근을 앞당겨 줄 도구"** 관점에서 카피를 작성하세요.

### 2.1 상황

기존 랜딩페이지에 제품 소개 히어로가 있지만, 그 위에 **셀러의 고통(Pain)을 직접 저격하는 새로운 히어로 섹션**을 추가하고 싶다.

### 2.2 AI에게 전달할 정보

**필수 정보:**

- [ ]  메인 헤드라인 텍스트 (고객의 핵심 Job 언어로)
- [ ]  서브 헤드라인 텍스트 (1~2개, Outcome 수치 포함)
- [ ]  CTA 버튼 텍스트 (사전 예약 / 무료로 시작하기)
- [ ]  기존 히어로와의 관계 (위에 추가)

**선택 정보:**

- [ ]  원하는 색상 톤 (다크 + 에메랄드, 딥블루 등)
- [ ]  강조하고 싶은 키워드 (밑줄/그라디언트 처리)
- [ ]  특별한 시각 효과 요청 (카운트업 애니메이션, 파티클 등)

### 2.3 프롬프트 예시

```
나는 현재 랜딩페이지도 좋지만, 기존의 히어로 영역이 꼭 필요했다고 생각해.
지금의 히어로 영역은 그대로 두고, 아래 내용의 히어로 영역을 최상단에 배치해줘.

---
헤드라인:
"내일 발주, 5분 만에 끝내세요"

서브 타이틀:
"쓰던 엑셀 파일만 올리면, AI가 SKU별 최적 발주량을 즉시 도출합니다."
"연동 없음 · 세팅 없음 · 가입 후 1분이면 첫 리포트 완성"

CTA 버튼:
"무료로 시작하기" (메인)
"3분 데모 보기" (서브, 아웃라인 스타일)

헤드라인에서 '5분'에 에메랄드 컬러 강조 + 카운트업 효과를 적용해줘.
CTA 버튼 아래에 작은 글씨로 "신용카드 불필요 · 50개사 베타 테스트 진행 중" 을 추가해줘.
```

### 2.4 결과 확인 체크리스트

- [ ]  새 히어로가 맨 위에 표시되는가?
- [ ]  기존 제품 소개 히어로는 그 아래에 그대로 있는가?
- [ ]  헤드라인/서브타이틀이 정확하게 표시되는가?
- [ ]  CTA 버튼이 사전 예약 폼 또는 회원가입 페이지로 연결되는가?
- [ ]  "5분"에 강조 효과가 적용되었는가?

### 2.5 추가 개선 요청 예시

> "헤드라인에서 '5분 만에' 부분에 밑줄이 왼쪽에서 오른쪽으로 그려지는 애니메이션을 넣어줘"

> "CTA 버튼 아래에 '발주 시간 95% 단축', '품절 손실 0원', '가입 후 1분 완성' 3개의 수치 뱃지를 수평으로 추가해줘. 각 수치는 스크롤 시 카운트업 애니메이션이 재생되게 해줘"

> "히어로 배경에 엑셀 시트가 대시보드 차트로 변환되는 은은한 모션 그래픽을 넣어줘"

## 3. 고정 헤더 네비게이션 추가하기

### 3.1 상황

페이지 스크롤 시에도 항상 상단에 보이는 네비게이션 바를 추가하고 싶다.

### 3.2 AI에게 전달할 정보

**필수 정보:**

- [ ]  왼쪽 영역: DeepDemand 로고/브랜드명
- [ ]  중앙 영역: 이동할 섹션 목록 (CJM 흐름 순서 기반)
- [ ]  오른쪽 영역: CTA 버튼 ("사전 예약하기" 또는 "무료로 시작하기")

**선택 정보:**

- [ ]  스크롤 시 스타일 변화 여부 (글래스모피즘)
- [ ]  모바일 메뉴 형태 (햄버거)

### 3.3 프롬프트 예시

```
최상단에 고정 헤더 네비게이션 바를 넣고 싶어.

네비바의 맨 왼쪽에는 DeepDemand 로고를,
중앙부에는 아래 섹션으로 바로 이동할 수 있는 링크들을 배치해줘:
- "이런 고민?" (Pain 섹션)
- "작동 방식" (3-Step 데모 섹션)
- "고객 후기" (리뷰 캐러셀)
- "요금제" (프라이싱 섹션)

맨 오른쪽에는 "사전 예약하기" CTA 버튼을 배치해줘.
스크롤 시에는 배경에 다크 글래스모피즘(반투명 블러)을 적용하고,
현재 보고 있는 섹션에 해당하는 링크에 에메랄드 언더라인 활성 표시를 해줘.
모바일(768px 이하)에서는 햄버거 메뉴로 전환해줘.
```

### 3.4 결과 확인 체크리스트

- [ ]  헤더가 스크롤해도 상단에 고정되어 있는가?
- [ ]  각 링크를 클릭하면 해당 섹션으로 스무스 스크롤되는가?
- [ ]  CTA 버튼이 사전 예약 폼으로 이동하는가?
- [ ]  스크롤 시 글래스모피즘 배경이 적용되는가?
- [ ]  현재 섹션에 맞는 네비 링크가 하이라이트 되는가?
- [ ]  모바일에서 햄버거 메뉴가 정상 동작하는가?

### 3.5 추가 개선 요청 예시

> "스크롤할 때 헤더 배경 블러를 backdrop-filter: blur(20px)로 강하게 적용해줘"

> "모바일 햄버거 메뉴가 열릴 때 각 링크가 위에서 아래로 순차적으로 슬라이드인 되게 해줘"

## 4. 섹션 순서 재배치하기 (CJM 기반 설계)

> [!IMPORTANT]
> **DeepDemand의 섹션 순서는 CJM(고객 여정) 5단계를 따라야 합니다.**
> 각 섹션이 촉발하는 고객의 감정과 생각에 따라 다음 섹션을 편성합니다.
>
> | CJM 단계 | 고객 감정 | 대응 섹션 |
> | --- | --- | --- |
> | **1. Trigger** | 짜증·불안 ("또 품절?!") | 히어로 (Pain 저격) |
> | **2. Setup & Aha** | 놀람·기대 ("엑셀만 올리면 된다고?") | 3-Step 작동 방식 데모 |
> | **3. Internal Buy-in** | 안도·확신 ("근거가 있으니 믿을 수 있겠다") | XAI 시각화 + 고객 후기 |
> | **4. Daily Routine** | 편안·만족 | 기능 상세 + 요금제 |
> | **5. Advocacy** | 자부심 | ROI 증명 + 최종 CTA |

### 4.1 상황

현재 섹션 순서가 고객의 심리적 흐름과 맞지 않아 CJM 기반으로 변경하고 싶다.

### 4.2 AI에게 전달할 정보

**필수 정보:**

- [ ]  이동할 섹션 이름
- [ ]  이동할 위치 (어떤 섹션 앞/뒤)
- [ ]  이동의 근거 (어떤 CJM 단계에 해당하는지)

### 4.3 프롬프트 예시

```
고객 후기(리뷰 캐러셀) 섹션을 요금제 섹션 앞으로 이동해줘.

이유: 고객이 요금제를 보기 전에 "나와 비슷한 셀러가 이미 효과를 봤다"는 사회적 증거를
먼저 확인해야 결제 전환율이 높아져. CJM 3단계(Buy-in)에서 신뢰를 확보한 뒤
4단계(Routine/요금제)로 넘어가는 흐름이야.
```

```
기능 상세 섹션을 '3-Step 작동 방식' 섹션 바로 아래로 이동해줘.

이유: 고객이 "오, 엑셀만 올리면 되는구나(Aha)"를 느낀 직후에
XAI 차트, 악성 재고 신호등 같은 상세 기능을 보여줘야 "정말 믿을 수 있겠다(확신)"로
자연스럽게 넘어갈 수 있어.
```

### 4.4 권장 섹션 순서 (CJM 기반)

```
1. [히어로] — "내일 발주, 5분 만에 끝내세요" (Trigger 저격)
2. [Pain 섹션] — "아직도 매일 밤 엑셀과 씨름하시나요?" (공감 형성)
3. [3-Step 작동 방식] — 업로드 → AI 분석 → 발주 리포트 (Aha Moment)
4. [XAI 기능 상세] — 예측 근거 차트 데모 (신뢰 구축)
5. [고객 후기 캐러셀] — "나와 같은 셀러의 목소리" (사회적 증거)
6. [Before/After 수치] — 2시간→5분, 품절 5건→0건 (ROI 증명)
7. [페르소나별 솔루션] — 이지훈/윤서연/최민호 맞춤 제안 (자기 투영)
8. [요금제] — 무료 체험 → 월 3만 원 구독 (전환)
9. [FAQ] — 데이터 보안, 엑셀 호환성 등 (Anxiety 해소)
10. [최종 CTA] — 사전 예약 + 대기 리스트 (행동 촉구)
```

### 4.5 주의사항

섹션 순서를 변경하면 네비게이션 링크 순서도 함께 변경되어야 합니다. AI가 자동으로 처리하지만, 결과를 반드시 확인하세요.

## 5. 구체적인 콘텐츠 섹션 보강하기

> [!TIP]
> **CJM 2단계 (Setup & Aha)** 에 해당합니다.
> 고객이 "이거 정말 쉬운 거 맞아?"라는 의문을 품는 순간, 3단계로 즉시 해소합니다.
> DeepDemand의 핵심 차별점은 **"Zero-Friction"** — 어떤 셀러 유형이든 엑셀만 올리면 됩니다.

### 5.1 예제 상황

다양한 이커머스 플랫폼/셀러 유형별로 지원 가능함을 보여주는 섹션을 추가하고 싶다.

### 5.2 프롬프트 예시

```
다음 내용을 요금제 위쪽 섹션으로 넣어서 보강해줘.
섹션 이름은 "어떤 셀러든, 엑셀만 있으면 됩니다" 로 해줘.

---
# 어떤 셀러든, 엑셀만 있으면 됩니다

## 플랫폼이 달라도, 품목이 달라도 — DeepDemand는 즉시 분석합니다

- 카페24 / 자사몰 셀러
  - 자사몰 주문 엑셀을 그대로 올리면 옵션별 발주량 즉시 도출
  - `#카페24`, `#자사몰`, `#다품종`

- 쿠팡 로켓그로스 셀러
  - 쿠팡 창고 입고량을 역산하여 장기 보관료 폭탄 방지
  - `#로켓그로스`, `#FBA`, `#입고최적화`

- 스마트스토어 파워셀러
  - 네이버 주문 데이터 기반으로 시즌별 수요 변동 예측
```

## 7. 가상 고객 리뷰 섹션 추가하기 (드래그 캐러셀)

> [!IMPORTANT]
> **CJM 3단계 (Internal Buy-in)** 의 핵심 무기입니다.
> 고객이 "작동 방식(Aha)"을 확인한 직후, 요금제를 보기 전에 배치합니다.
> **"내 목소리처럼 들리는 이야기"** — JTBD 4 Forces에서 추출한 실제 고통/기대를 반영합니다.
>
> - **Push** 기반 리뷰: "엑셀에 지쳐서...", "품절 때문에..."
> - **Pull** 기반 리뷰: "1분 만에 결과가...", "근거 차트 보고 안심..."
> - **Habit 극복** 리뷰: "처음엔 내 눈으로 봐야 했는데..."
> - **Anxiety 해소** 리뷰: "데이터 보안이 걱정됐는데 24시간 삭제라니..."

### 7.1 상황

다양한 셀러 유형의 후기를 좌우 드래그로 볼 수 있는 캐러셀 형태로 표시하고 싶다.

### 7.2 AI에게 전달할 정보

**필수 정보:**

- [ ]  섹션 제목
- [ ]  그룹 구분 (페르소나 스펙트럼 기반)
- [ ]  각 리뷰 정보:
    - 이름 (익명화)
    - 역할/셀러 유형
    - 리뷰 내용 (JTBD 4 Forces 반영)
    - 별점 또는 수치 성과

**선택 정보:**

- [ ]  그룹별 색상 (Core: 에메랄드, Adjacent: 블루)
- [ ]  '드래그 가능' 힌트 표시 여부
