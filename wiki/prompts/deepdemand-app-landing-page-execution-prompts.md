## 📋 단계별 실행 프롬프트 세트

### 1단계: 네비게이션 고도화 및 히어로 섹션 개편
> **목적:** CJM 1단계(Trigger) 타겟팅. 스크롤 위치 감지 네비바 구현 및 첫인상에서 다품종 셀러의 Pain을 즉각 자극하고 신뢰감을 주는 히어로 구성.

```markdown
WHAT: 
1. 최상단 고정 네비게이션 바(nav)에 중앙 링크들("이런 고민?", "작동 방식", "고객 후기", "요금제")을 추가하고, 스크롤 상태에 따라 다크 글래스모피즘(backdrop-blur-md, bg-[#111315]/80, 경계선 border-white/5) 스타일이 적용되게 개선해줘.
2. 히어로 섹션의 카피와 CTA 구조를 아래 내용으로 개편해줘.
   - 메인 헤드라인: "내일 발주, 5분 만에 끝내세요" (단, '5분' 단어는 에메랄드 컬러 강조 스타일 적용)
   - 서브 타이틀: "쓰던 엑셀 파일만 올리면, AI가 SKU별 최적 발주량을 즉시 도출합니다."와 "연동 없음 · 세팅 없음 · 가입 후 1분이면 첫 리포트 완성"의 두 줄로 구성.
   - 메인 CTA 버튼: "무료로 시작하기" (기존 /onboarding 이동 유지, 호버 시 scale-105 효과 적용)
   - 서브 CTA 버튼: "3분 데모 보기" (아웃라인 스타일 버튼 추가)
   - CTA 아래 서브 텍스트: "신용카드 불필요 · 50개사 베타 테스트 진행 중" 추가

WHERE: src/app/page.tsx의 Home 컴포넌트 내 네비게이션(<nav>) 및 히어로 섹션(<section>)

HOW:
- React의 useState와 useEffect를 사용하여 윈도우 스크롤 위치가 20px 이상일 때 네비게이션 바에 글래스모피즘 배경을 활성화하는 상태(isScrolled)를 추가해줘.
- 네비게이션 중앙 링크 클릭 시 각 섹션으로 스무스 스크롤되도록 `<a href="#id">` 혹은 관련 스크롤 동작을 적용해줘.
- 기존의 @/components/ui/button 및 lucide-react 아이콘을 활용하고, 필요한 경우 라이브러리 추가 임포트 진행해줘.

WHY:
- 사용자가 페이지 진입 시 가장 먼저 마주하는 화면에서 직관적인 솔루션의 편의성을 인지하고, 탐색할 경로(네비게이션)를 명확히 보여주기 위함.
```

### 2단계: Pain 공감 및 플랫폼 범용성("어떤 셀러든") 섹션 추가
> **목적:** CJM 2단계(Setup & Aha) 타겟팅. 셀러들이 매일 밤 겪는 수기 엑셀의 복잡함을 시각적으로 공감하고, 자사몰/쿠팡/네이버/의류 등 어떠한 형태의 데이터도 엑셀만 있으면 바로 적용 가능하다는 장벽 해소.

```markdown
WHAT:
1. 히어로 섹션 아래와 3단계 작동 방식 섹션 사이에 "아직도 매일 밤 엑셀과 씨름하시나요?"라는 타이틀의 Pain 공감 섹션을 추가해줘.
   - 수기 엑셀 발주로 인해 밤 11시까지 근무하거나, 품절로 고객을 잃는 문제를 드러내는 2열 카드 레이아웃을 작성해줘.
2. 3단계 작동 방식 섹션 아래에 "어떤 셀러든, 엑셀만 있으면 됩니다"라는 이름의 플랫폼 범용성 섹션을 추가해줘.
   - @/components/ui/card 및 @/components/ui/badge를 임포트하여 아래 4개 유형을 카드 그리드로 구성해줘.
     - 카페24 / 자사몰 셀러: 자사몰 주문 엑셀 그대로 업로드, 옵션별 발주량 즉시 도출 (#카페24, #자사몰, #다품종)
     - 쿠팡 로켓그로스 셀러: 쿠팡 창고 입고량을 역산하여 장기 보관료 폭탄 방지 (#로켓그로스, #FBA, #입고최적화)
     - 스마트스토어 파워셀러: 네이버 주문 데이터 기반으로 시즌별 수요 변동 예측 (#스마트스토어, #계절상품)
     - 동대문 기반 의류 MD: 사이즈/컬러별 디테일 옵션의 악성 재고 리스크 사전 차단 (#동대문, #옵션관리, #사입)

WHERE: src/app/page.tsx의 히어로 섹션 아래 위치.

HOW:
- @/components/ui/card에서 Card, CardHeader, CardTitle, CardDescription, CardContent 컴포넌트들을 임포트하여 사용해줘.
- 각 플랫폼 카드에 에메랄드 계열 또는 은은한 화이트 보더 보더 호버 효과를 주어 세련된 다크 글래스 디자인을 유지해줘.
- 4열 그리드(grid grid-cols-1 md:grid-cols-2 lg:grid-cols-4 gap-6)를 활용해 데스크톱과 모바일 레이아웃에 모두 대응해줘.

WHY:
- 자신의 판매 플랫폼이 지원되는지 불안해하는 고객들에게 "엑셀 파일 하나로 모두 완결된다"는 메시지를 주어 도입 장벽을 최소화(Zero-Friction)하기 위함.
```

### 3단계: 페르소나 솔루션 카드 및 사용 시나리오 섹션 추가
> **목적:** CJM 3단계(Internal Buy-in) 타겟팅. 페르소나별 4 Forces(Push/Pull/Habit/Anxiety)를 해소하는 실질적인 문제 해결 시나리오를 제시하고, 타겟 고객이 자신의 문제를 투영할 수 있는 사용 시나리오 섹션을 구성.

```markdown
WHAT:
1. "이런 문제를 해결합니다"라는 제목으로 페르소나별 맞춤형 해결책 섹션을 추가해줘.
   - 대표 페르소나 3명(이지훈-다품종 셀러, 윤서연-쿠팡 로켓그로스 셀러, 최민호-의류 MD)의 프로필, 겪고 있는 문제, 감정 상태, DeepDemand의 해결법을 포함한 카드 레이아웃을 작성해줘.
   - 카드 호버 시 뒷면에 솔루션이 나타나는 구조 또는 탭(Tabs)을 이용해 자연스럽게 전환되는 UI로 구성해줘.
   - 중요: "후기"나 "리뷰" 표현을 절대 사용하지 말 것. "이런 상황이신가요?", "이렇게 해결합니다" 프레임으로 작성.
2. "이런 분들이 DeepDemand를 기다리고 있습니다" 섹션을 추가하고, 좌우 드래그가 가능한 인터랙티브한 사용 시나리오 캐러셀을 구현해줘.
   - @/components/ui/carousel 컴포넌트를 사용하여 아래 시나리오 카드들을 스와이프할 수 있게 해줘.
     - 그룹 1 (다품종 자사몬 셀러): "매일 밤 엑셀로 발주 계산하다 가정까지 흔들리는 셀러를 위해" — 목표: 발주 시간 단축 + 품절 방지
     - 그룹 2 (3PL/도매 인프라 셀러): "고객사의 재고 위험을 미리 모니터링하고 싶은 물류센터 소장을 위해" — 목표: 유휴 시간 절감 + 선제적 입고 안내
   - 각 시나리오 카드에는 에메랄드/블루 계열의 그룹 태그(Badge)를 시각적으로 강조해줘.
   - 별점(⭐)은 사용하지 마. 비포/애프터 수치는 "목표 효과"로 표현해줘 (예: "목표: 발주 업무 시간 95% 단축").

WHERE: src/app/page.tsx의 ROI 소요시간 비교 섹션 아래 위치. 섹션 id는 "scenarios"로 지정.

HOW:
- @/components/ui/carousel에서 Carousel, CarouselContent, CarouselItem, CarouselNext, CarouselPrevious를 임포트하여 레이아웃을 구현하고, 모바일에서는 터치 스와이프가 자연스럽게 동작하도록 처리해줘.
- 별점(⭐)은 사용하지 말 것. 실제 사용자가 없는 사전 출시 단계이므로 "후기"가 아닌 "목표 시나리오" 프레임을 유지해줘.

WHY:
- 단순 텍스트 나열을 넘어 인터랙티브한 요소로 고객의 시선을 잡고, "이건 내 여야기네" 하는 자기 투영을 유도함으로써 제품 가치에 대한 관심과 사전 예약 의향을 형성하기 위함.
```

### 4단계: 요금제, FAQ 아코디언 및 사전 예약/최종 CTA 보강
> **목적:** CJM 4단계(Routine) 및 5단계(Advocacy) 타겟팅. 명확한 요금제 제시를 통해 전환 경로를 확보하고, 데이터 보안 등의 최종 불안(Anxiety) 요소를 FAQ 아코디언으로 해소한 뒤 이메일 수집 폼을 통한 리드 제네레이션 완성.

```markdown
WHAT:
1. "합리적인 성장 파트너 요금제" 섹션을 추가해줘.
   - 무료 체험 요금제 카드(0원, 기본 AI 예측, 1개 계정)와 스타터 요금제(월 3만원, 고정밀 AI 분석, XAI 리포트 제공)의 2열 요금제 레이아웃을 배치해줘.
2. @/components/ui/accordion을 활용하여 자주 묻는 질문(FAQ) 섹션을 구현해줘.
   - 질문 1: "사용하던 엑셀 서식을 그대로 업로드해도 되나요?" (답변: 네, 어떤 플랫폼의 엑셀 양식이든 상관없이 AI가 주요 열을 자동 감지하여 분석합니다.)
   - 질문 2: "제 판매 및 고객 데이터의 보안은 안전한가요?" (답변: 업로드된 파일은 분석 즉시 24시간 이내에 서버에서 완전히 영구 삭제되며, 예측 엔진에 기계 학습용으로 무단 사용되지 않습니다.)
   - 질문 3: "API 연동이나 추가 개발이 필요한가요?" (답변: 전혀 필요 없습니다. 로그인 후 엑셀 드롭 한 번으로 모든 기능을 설치 없이 즉시 웹 브라우저에서 이용하실 수 있습니다.)
3. 하단 최종 CTA 섹션을 메인 히어로 톤앤매너에 맞게 강화하고, 사전 예약/알림 신청용 이메일 입력 폼(@/components/ui/input)과 버튼을 추가해줘.

WHERE: src/app/page.tsx의 고객 후기 아래 및 푸터(Footer) 위.

HOW:
- @/components/ui/accordion의 Accordion, AccordionItem, AccordionTrigger, AccordionContent 컴포넌트들을 임포트하여 부드러운 아코디언 동작을 구현해줘.
- 이메일 입력 영역은 Tailwind의 flex 레이아웃으로 모바일에서는 수직, 데스크톱에서는 수평 배치(flex flex-col sm:flex-row gap-2 max-w-md mx-auto)로 예쁘게 가공해줘.

WHY:
- 잠재 고객이 가입이나 예약을 꺼리는 최종 불안 요소(보안, 호환성)를 해소하고, 이메일 주소를 쉽게 입력하게 함으로써 이탈율을 줄이고 초기 가입 전환율을 극대화하기 위함.
```
